% waitOP:
%       0-NOP: DO NOT Wait for any process and start at time0
%       1-TRN: Wait for src of waitID to complete sending TAIL flit
%       2-CMP: Wait for dst of waitID to complete computeProcess()
% waitID:
% Wait and process data from multiple taskIDs
%       [1 2 3] --> have to wait for taskID=1,2,3 complete
%       [-1]    --> no taskID to wait, begin current taskID at time0
% assumptions:
%   Either one of [src] [dst] can contain more than 1 element in each task
%       [src]   [dst]
%       [1 4 5] [3]      --> CORRECT
%       [3 1 2] [3 9 11] --> WRONG
%   PE will start computeProcess() and stop receive flits,
%       when TAIL flit of the taskID arrives at source 
% layer: 
%       indicates which NN layer 
% min_vol: 
%       2D filter size, e.g. 5x5 filter, min_vol = 5*5 = 25 
% total_vol: 
%       2D output size, e.g. 11x11 output, total_vol = 11*11 = ~128 
% src_:  
%       src_minVol: # of computed data to generate one flit in src (acts as "Compression")
%       src_totalVol: Sum of data src PE needs to transmit (NOT same as dst_totalVol)
%        IF (src_minVol == -1) --> packet.size == totalVol [e.g. from IFM --> Conv]
%        src_ data is provided to src PE by traffic table
% dst_:  
%       dst_minVol: # of received data to begin compute in dst
%       dst_totVol: Sum of data dst PE to receive (NOT same as src_totalVol, most of the time)
%       if (dst_minVol == -1) --> no compute operation in dst PE [e.g. final output layer]
%        dst_ data is SENT by src PE to dst PE
% How does compute_data work? PE0->PE1->PE2
%       > dst_minVol is reached at PE1, trigger compute, move the recvBytes to processedBytes, stop when dst_totalVol is hit
%       > when procesedBytes in src_minVol of PE1 reached, send one flit to PE2 until reach src_totalVol
% For correct pipelinig of tasks:
%       > Ensure a src-dst pair is proceeded with a subsequent relevant src-dst pair
%       > e.g. Pipeline: PE0->PE1->PE2
% 		> 		Traffic Table: pair#1 PE0->PE1 pair#2 PE1->PE2 
%		> In same traffic row, the [src] must be aligned with [waitID]
%		> e.g. src [1 2], waitID [3 4]; Implies that srcPE_1 is waiting taskID 3, srcPE_2 waiting takdID 4;
% taskID layerID [src] [dst] src_minVol src_totalVol dst_minVol dst_totalVol [waitID] [nextID] waitOP
